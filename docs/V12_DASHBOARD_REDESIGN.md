# V12 Dashboard Redesign

V12 is a visual/professional redesign of both the coach and client dashboards while keeping the existing Jay Aesthetics black/red brand.

Changes:
- stronger sidebar hierarchy
- premium top navigation/header
- dark readable client-management UI
- no white-on-white client detail sections
- improved admin overview
- professional metric cards
- structured quick-access panels
- upgraded client dashboard
- clearer subscription/program status
- better spacing, typography and responsive layout

No database changes are required.

Run:
```bash
npm install
npm run dev
```
