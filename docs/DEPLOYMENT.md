# Deployment checklist

1. Buy/connect `jayaesthetics.com`.
2. Host frontend on Vercel, Netlify or Cloudflare Pages.
3. Host API on Render, Railway, Fly.io, AWS, DigitalOcean, or another Node host.
4. Use managed PostgreSQL.
5. Set production environment variables.
6. Configure `WEB_ORIGIN` to the real domain.
7. Add real Razorpay credentials.
8. Configure Razorpay webhook verification before accepting real money.
9. Add HTTPS.
10. Add database backups.
11. Add monitoring/error tracking.
12. Add Privacy Policy, Terms and Refund/Cancellation Policy.
13. Add client consent for progress photo storage/use.
14. Load-test staging before launch.
